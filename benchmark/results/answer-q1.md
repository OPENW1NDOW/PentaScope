# 笔试第 1 题回答

## 场景选取

我选取的编程任务是：在我个人开发的多 Agent 竞品分析系统（PentaScope）中，将 Analyzer Agent 从串行分析改为并行分析。该系统使用 LangGraph 编排 4 个 AI Agent 协作完成从数据采集到报告产出的全链路，技术栈为 Python + asyncio + Pydantic v2 + FastAPI。

具体任务是：当待分析竞品 ≥3 个时，将竞品拆分为 2 组并发调用 LLM，合并结果后返回，将单次分析耗时从 ~240s 降到 ~120s。任务涉及异步并发编排、Pydantic 模型合并、部分失败降级、现有架构约束兼容、以及配套的 7 个单元测试编写。

## 测评方法

统一使用 Claude Code CLI 的 agent 模式（auto-mode），给四个模型完全相同的 prompt，从同一个 git commit 拉出独立分支，让模型自主完成"读代码 → 实现 → 跑测试 → 修复 → 提交"全流程。不做人工追问或引导。

## 各模型表现

**DeepSeek v4-pro**：耗时约 17 分钟，pytest 运行 18 次，4 次 Edit 操作。采用 dict 级合并策略——每组独立做 Pydantic 校验后以 raw dict 形式合并，最后一次性构造完整对象。代码新增 450 行，分组逻辑细致（余数均匀分配），日志格式规范（中文"分组 X"+ 耗时），整体设计合理。小瑕疵：合并后没有对最终 dict 做完整性校验，SWOT 去重没处理 point 为空的边界。

**Claude opus-4.8**：耗时约 15 分钟，pytest 运行 12 次（最少），4 次 Edit。代码新增仅 344 行（最少），使用 `model_copy(deep=True)` 做基底逐字段累加，SWOT 去重直接操作 Pydantic model 对象（类型安全），正确处理了 `swot=None` 边界。代码风格完美融入项目——中文日志、async 模式、命名规范全部一致。是唯一在首轮实现中几乎不需要反复调试的模型。

**GPT 5.5**：耗时约 19 分钟，pytest 运行 27 次（最多），7 次 Edit。额外定义了通用去重函数（用 JSON 序列化做 key），设计偏过度工程。还多修改了 DECISIONS.md 和 PROGRESS.md 两个不该动的文件（范围控制不够精确）。反复调试轮次最多，反映首次产出的正确率较低。

**GLM 5.2**：耗时约 18 分钟，pytest 运行 23 次，10 次 Edit（最多）。直接 import Pydantic 子类型构造合并结果，类型明确。但 `_split_profiles` 函数签名接收 `groups` 参数却内部硬编码 `mid = len // 2`（参数无效），说明实现与设计意图不一致。edit 次数最多表明代码不是一步到位。

## 性能优劣排序

**Claude opus > DeepSeek v4-pro > GLM 5.2 > GPT 5.5**

排序原因：
1. **Claude opus 第一**：效率最高（最少调试轮次）、代码最简洁、架构理解最深（Pydantic model_copy、swot=None 边界处理），是唯一接近"一次到位"的模型。
2. **DeepSeek 第二**：效率与 Claude 接近（少 2 分钟差距），dict 级合并是有意义的性能优化思路（少一次 Pydantic 构造开销），分组逻辑细致。
3. **GLM 第三**：功能完整且正确，但 10 次 Edit + 23 次 pytest 说明过程中反复试错；split 函数的参数/实现矛盾暴露了设计一致性问题。
4. **GPT 第四**：虽然最终正确，但 27 次 pytest、多改了无关文件、去重函数过度设计，整体表现最不稳定。

## 如果模型变强了，如何调整评测

1. **提高任务复杂度**：当前任务四个模型都能完成，区分度主要在效率和代码质量。未来可换更难的任务——如跨模块重构（同时改 schema + agent + graph + 测试 4 层）、或涉及并发竞态的 bug 修复。
2. **缩减上下文提示**：当前 TASK.md 给了详细的合并逻辑说明和技术提示。可以只给高层需求（"提速 50%"），不提实现路径，考察模型的方案设计能力。
3. **增加一次性通过率权重**：如果模型都能一次通过测试，可以改为"禁止自动修复"模式（只看首次产出），区分度会更大。
4. **引入代码审查维度**：让模型 A 的产出由模型 B 审查，看能否发现对方代码的真实缺陷（如 DeepSeek 的合并后未校验、GLM 的参数失效），衡量深层理解能力。
