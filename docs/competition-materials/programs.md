# AIGC系统
1. 电商场景 AIGC 带货视频生成系统
    在 TikTok Shop 国际电商快速发展的背景下，短视频已成为商家获取流量和提升成交的关键载体。本课题聚焦真实业务场景，邀请你基于 React、Node.js、TypeScript、火山引擎 OpenAPI 与开源模型，打造一个面向商家的 AIGC 带货视频生成系统。 带货视频生成系统希望可以实现商家端到端自动生成视频，支持 Prompt 调整、分镜干预、素材混剪等多项视频生成功能；同时设计流量分析诊断能力，反哺视频生成。课题不仅关注生成高质量的视频，也强调对电商交易转化效果，鼓励参赛者探索 AI Agent 在电商增长中的创新应用。

2. 爆款结构迁移引擎：从样例拆解到视频重组的 AI 创作平台
    面向短视频创作场景，设计并实现一个能够"学习优质视频结构，并迁移到新内容创作中"的 AI 系统。参赛者可选择一条或多条优质样例视频，分析其在开头 hook、镜头节奏、字幕布局、画面包装、音乐卡点、卖点推进或结尾转化等方面的特点，并将这些结构化规律迁移到用户提供的素材、主题或商品信息中，生成新的短视频方案。 系统不要求直接复刻样例内容，而更强调对"创作方法"的抽象、重组与表达。作品可结合真实素材剪辑、AIGC 生成、包装设计、多版本对比、自然语言编辑等能力，探索更智能、更可控、更具创意的视频生产方式。 技术建议：建议结合 React / TypeScript / Node.js 搭建基础系统，配合 LLM、多模态理解模型、语音转写、视频/图像生成能力完成脚本分析、素材理解与内容生成；可结合 FFmpeg/OpenCV 进行抽帧、剪辑、字幕或封面处理。鼓励同学围绕结构迁移、画面包装、可编辑时间线、多版本生成、效果评估等方向自由发挥。

# Agent智能体
1. AI 驱动的竞品分析 Agent 协作系统
    在企业产品研发中，传统的竞品分析往往面临流程繁琐重复、信息源分散且极度依赖个人行业认知的痛点。本课题聚焦高效的市场洞察场景，邀请你打造一个"AI 驱动的竞品分析 Agent 协作系统"，模拟真实的数字调研小组，通过多个专职 Agent 的协同，自动完成从公开信息采集到结构化竞品报告输出的全链路工作。 该系统需构建采集、分析、撰写与质检等独立 Agent 角色，基于自定义的竞品知识 Schema 进行协作，并形成 DAG 式的任务流转与交叉审查反馈闭环。课题不仅要求实现深度的自动化商业分析，还极度强调结果的溯源能力与系统的可观测性，确保每条分析结论均有据可查，每一个 Agent 的决策过程与中间产物都完全透明。

2. 实现一个基于 RAG 的多模态电商智能导购 Agent
    基于 iOS/Android 原生框架、Node.js/Python/Go 等后端服务、向量数据库及大模型 OpenAPI 等技术栈，构建一个打通"意图理解-智能咨询-决策辅助"核心路径的电商 AI 导购系统。 要求实现一个能够深度理解商品属性、用户意图并提供个性化决策支持的智能 Agent。通过上传非结构化的商品详情与营销文档构建专属知识库，系统通过 RAG 技术确保回复的专业性与准确性；在客户端，需利用原生技术栈打造媲美"豆包"的流式交互体验，同时支持商品卡片实时渲染、多模态（文字/图片）输入解析。 同时，课题需构建一套端到端的质量评测与反馈闭环，通过对典型导购场景下的回答准确率、知识检索精度及多轮对话逻辑进行定量评估，反哺 Prompt 策略优化与知识库迭代，旨在验证该工程方案在模拟商业场景下的技术可行性与交互质量，并为电商导购从"信息搜索"向"辅助决策"的代际跨越提供工程实践参考。

3. AgentHub - 多 Agent 协作平台
    在大模型与 AI Agent 技术快速发展的背景下，多 Agent 协作已成为提升复杂任务执行效率的关键趋势。本课题聚焦 AI 驱动的开发与协作场景，要求学生基于统一适配器层与主流 Agent 平台（如 Claude Code、Codex），打造一个 IM 聊天式的多 Agent 协作平台（AgentHub）。 AgentHub 系统致力于实现类似飞书/微信的自然交互体验，支持单聊、多会话并行以及通过 @ 指令实现的群聊协作；同时集成 Orchestrator 协调器进行任务拆解，并提供代码 Diff、网页预览及一键部署等全流程功能。课题不仅考察系统的功能完整度与用户体验，更强调参赛者在 TRAE 协作、Prompt 工程及架构选型中的创新思考与实践。

4. AI 狼人杀 — 多智能体协作与博弈的 Agent Team 实战
    基于多 Agent 协作框架，构建一个能够自主完成信息不对称博弈的狼人杀 Agent Team 系统。课题核心在于多智能体的协作/对抗与交互机制设计：每个 Agent 根据其扮演角色（狼人、预言家、女巫等）拥有独立的目标、策略与行动空间，在严格信息隔离的约束下进行推理、发言与决策。系统需搭建完整的对局引擎，驱动回合流转与胜负裁决，并输出结构化日志以实现全程可观测。加分项为前端观战 UI，支持纯 AI 对战或人机混战，直观呈现多 Agent 的实时博弈过程。 进阶方向（三选一）： ① 通用 Agent — 探索"读懂自己→修改自己→运行自己"的自演化系统，从「通用 Agent」演化为「狼人杀多角色 Agent」； ② 评测+复盘 — 构建结果评测、过程评测等多维可量化评测体系，基于此完成任意游戏的复盘归因，并产出不同版本、不同模型 Agent 同台竞技的 Leaderboard； ③ 自进化 Agent — 实现"对局→分析→优化→再对局"自进化循环，使各角色 Agent 在多局迭代中持续提升胜率。

# 电商系统
1. 短视频时代交易新玩法：抖音电商直播竞拍全栈系统设计
    在直播电商生态中，珠宝、二手奢侈品等高价值非标品难以统一定价，而"动态竞拍"能通过强互动与竞技感最大化商品价值。本课题聚焦高并发与实时交互场景，邀请你基于 React、WebSocket 与 Node/Go 等全栈技术，结合开源 AI 模型，打造一个完整的直播竞拍闭环系统。 该引擎需实现从竞拍商品上架、自定义规则设定、毫秒级实时出价参与、动态排名计算到最终落锤成交的全链路流转。课题不仅考验参赛者在 WebSocket 实时通信、状态一致性上的硬核架构能力，更鼓励探索 AI 在动态定价与竞拍气氛营造中的创新应用。

# 移动应用
1. 基于短剧内容理解的即时互动激发
    在短剧生态快速爆发的背景下，剧情高光与反转等名场面往往能唤起用户强烈的情绪表达诉求，但传统的弹幕和评论输入门槛高且易中断观看体验。本课题聚焦短剧内容消费场景，邀请你结合算法与大模型能力，打造一个面向独立客户端的"即时互动激发"产品方案。 该系统希望实现对海量短剧内容的深度理解，精准识别各类剧情高光（如冲突、反转、甜蜜撒糖等）并作为数据基础下发。同时，需设计出新颖低门槛的端上可视化交互形式，并构建高响应效率的后台闭环。课题要求参赛者完成从"高光点识别与存储"到"客户端互动效果渲染"的完整 MVP 链路，全面升级用户的剧情参与感与情绪体验与参与感。

2. 智能识物比价购物 AI APP 助手
    基于客户端/前端技术、服务端技术（Node.js / Go / Java 等）、火山引擎 OpenAPI、开源模型等技术栈，在客户端（Android / iOS / 鸿蒙）上实现一个面向消费者的 AI 拍照识物购物助手。 调用手机摄像头拍摄商品实物，AI 识别商品类目与属性（如款式、颜色、品牌），自动匹配全网相似商品并以卡片列表形式展示，支持跨平台比价与历史价格趋势查看，用户可通过自然语言追加筛选条件（如"要便宜点的"、"只看旗舰店"）后 AI 推荐实时更新列表，帮助消费者快速找到最具性价比的商品。 补充说明：禁用端侧 AI SDK，如豆包 SDK、Google ML Kit、百度 AI SDK、阿里云视觉智能 SDK 等。

# AI工程工具
1. 实现一个可以端到端交付全栈项目的"超级个体"
    以开源全栈博客仓库 Conduit（前后端单仓 monorepo）作为实验田，实现一个端到端交付全栈需求的系统。 要求能让产品经理在平台内通过对话完成"需求澄清 → 方案拆解 → 模块定位 → 代码生成 → 自动化测试 → 代码部署"全链路；各阶段均可人工介入（追加澄清、修订方案、调整模块边界、修订测试用例等）；最终在该开源仓库上稳定产出可提测的代码；实现知识回写，反哺后续迭代需求全流程。

2. LabelHub 数据标注平台
    在大模型与 Agent 训练调优极度依赖高质量业务数据的背景下，提升数据生产效率与标注质量成为 AI 研发的核心环节。本课题聚焦真实的 AI 数据生产场景，邀请你完成前端、后端及审核 Agent 的开发，打造一套端到端的 Web 数据标注平台（LabelHub）。 该平台需完整覆盖数据生产的全生命周期，支持任务负责人配置任务说明，并以拖拽或组件化的方式动态搭建包含多种表单的标注页面；同时实现标注员在线分发与提交、基于自定义评测标准的 AI 自动预审、多角色人工审核流转及多格式数据导出。课题将全面考察参赛者在复杂动态表单架构设计、长链路工作流状态流转以及 AI 质检 Agent 落地等维度的全栈工程能力。
