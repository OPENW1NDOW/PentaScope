# 竞品分析 SOP（标准化操作流程）

> 综合来源：ProcessOn《产品经理如何做出真正有用的竞品分析》、人人都是产品经理《制作竞品分析的六步详拆解》、策略人藏锋《如何做竞品分析（2026年版）》

---

## 一、明确分析目标（Why）

### 价值定位
竞品分析的质量上限，在目标确定的那一刻就已经决定了。目标模糊会导致后续所有环节失焦——选错竞品、采集无关信息、分析流于表面、结论无法落地。这一步是整个 SOP 的地基。

### 核心原则
**目标决定一切。** 竞品分析是手段而非目的，最终要回答"这对我到底有什么用"。

### 工作内容
1. **回答"为什么要做这次分析"** —— 是立项决策、功能迭代、定价策略，还是市场抢占？
2. **明确分析的产品阶段** —— 进入期、成长期、成熟期的分析侧重完全不同
3. **界定分析范围** —— 是全链路全景分析，还是聚焦某个功能模块？
4. **确定期望产出** —— 要的是资讯（了解动态）、知识（理解规律），还是行动方案（指导决策）？

### 产出物
→ **分析目标说明书**（1-2 页）：包含分析背景、核心问题、分析范围、期望产出形式，作为后续所有步骤的"锚点"。

### 目标类型与侧重

| 产品阶段 | 分析侧重 | 核心问题 |
|---------|---------|---------|
| 进入期（开拓阶段） | 行业格局、市场机会 | 做什么产品？ |
| 成长期（成长阶段） | 竞争策略、功能差异 | 怎么做出差异化？ |
| 成熟期（防守阶段） | 市场份额监控 | 如何守住用户？ |

### 常见分析动机
- **立项决策**：分析市场格局、头部竞品优劣势、用户痛点、差异化机会
- **功能迭代**：分析竞品某功能模块、交互细节、用户反馈
- **定价策略**：分析竞品价格体系、收费模式、付费意愿
- **市场抢占**：分析渠道布局、营销策略、用户增长方式

### 关键注意事项
1. 先问自己：希望通过竞品分析获得的是**资讯**、**知识**还是**行动方案**？
2. 不同目标决定了竞品范围、分析维度和结论形式
3. 带着问题去分析，避免被竞品某个功能吸引而偏离方向

## 二、寻找与筛选竞品（Who）

### 价值定位
竞品选错了，后面所有分析都是白费力气。选竞品不是"找同类产品"，而是"找能回答我问题的参照物"。这一步决定了分析的参照系是否有效——选得太窄会遗漏关键对手，选得太宽会分散精力。

### 工作内容
1. **先自问三个问题再动手搜索**：我要解决什么问题？谁在这个问题上做得好/差？它们各自能给我什么参考？
2. **按竞品分类体系广泛搜索**，用多种渠道（关键词、应用商店、行业报告、内部推荐）建立候选清单
3. **按分类体系归类**，明确每个候选竞品属于核心/标杆/间接/潜力/替代/翘楚/避坑中的哪一类
4. **用二八原则裁剪**，最终保留 3-5 个高质量竞品（功能迭代场景 2-3 个，市场格局场景可扩至 5 个）

### 产出物
→ **竞品清单表**：包含竞品名称、分类类型、选择理由、拟分析的侧重点，作为信息采集的输入清单。

### 2.1 竞品分类体系

| 竞品类型 | 定义 | 分析价值 |
|---------|------|---------|
| **核心竞品（直接）** | 目标用户相同，核心功能高度相似 | 找相似设计与差异化设计 |
| **标杆竞品** | 体量更大、品牌力更强，引领行业趋势 | 学习成熟模式和前沿玩法 |
| **间接竞品（重要）** | 用户群体高度重合，但解决方式不同 | 找相同设计，降低用户迁移成本 |
| **潜力竞品** | 体量不如我们，但策略打法有亮点 | 发现创新机会 |
| **替代竞品** | 不同细分行业，但解决同一层面需求 | 拓宽视野 |
| **翘楚竞品** | 无直接竞争关系，但产品理念/技术前瞻 | 找灵感设计，跳出"抄袭"困境 |
| **避坑竞品** | 反面教材 | 确定什么不能做 |

### 2.2 寻找竞品的渠道
- **关键词搜索**：浏览器搜索（关键词不必太具体）
- **应用商店/排行榜**：七麦数据、酷传咨询、it橘子
- **行业报告**：易观智库、比达咨询、企鹅智库
- **内部推荐**：向公司产品经理询问（最精准）
- **行业人脉**：脉脉等平台找行业大牛
- **第三方数据**：SimilarWeb、App Annie、QuestMobile

### 2.3 筛选原则
- **二八原则**：在直接竞品中选 1-2 个头部，再挑个别优秀的间接/翘楚竞品
- **不在量多，而在质优**
- 功能迭代聚焦 2-3 个直接竞品；市场格局判断可扩至 5 个左右

### 关键注意事项
1. 不要一上来就把沾边的品牌全看一遍
2. 先想清楚三个问题：我要解决什么问题？谁做得好/差？各自能给我什么参考？
3. 不同项目场景，竞品选择逻辑不同

## 三、多渠道信息采集（What）

### 价值定位
信息是分析的原材料。原材料的质量和完整度直接决定分析的深度。采集不足会导致结论缺乏依据，采集过量则会淹没分析重点。这一步的核心挑战是：在"信息过载"和"信息不足"之间找到平衡点。

### 工作内容
1. **根据目标和竞品清单，确定每个竞品需要采集的信息维度**（不必全采，紧扣目标）
2. **按渠道矩阵逐一采集**：先公开渠道建立基础认知，再数据渠道获取量化指标，最后用户渠道补充真实反馈
3. **亲身体验竞品产品**：注册账号、走完核心流程、截图记录每一步操作路径和关键节点
4. **建立竞品信息档案**：为每个竞品建立独立的信息卡片，按维度分类整理原始素材
5. **交叉验证**：同一信息尽量从两个以上渠道确认，避免被单一来源误导

### 产出物
→ **竞品信息档案**（每个竞品一份）：包含原始数据、截图、用户评价摘录、关键指标等，作为分析框架的输入素材。

### 3.1 信息采集渠道矩阵

| 渠道类型 | 具体来源 | 适用场景 |
|---------|---------|---------|
| **公开渠道** | 官网、App Store 评论、官方文档、博客、媒体采访 | 产品定位、功能了解 |
| **数据渠道** | 七麦数据、SimilarWeb、App Annie、QuestMobile | 用户规模、增长趋势 |
| **用户渠道** | 用户访谈、问卷、社交媒体、问答网站 | 用户真实反馈 |
| **亲身体验** | 亲自注册使用，截屏记录操作路径 | 功能分析、体验对比 |
| **行业报告** | 酷传咨询、易观智库、比达咨询 | 行业趋势、市场份额 |

### 3.2 需采集的核心信息
- **行业层面**：产业链图、市场规模及增长趋势、国家政策方向
- **公司层面**：团队规模、核心目标、品牌影响力、盈利数据、投资占比
- **产品层面**：核心功能、版本更新、注册用户量、日/月活数据
- **用户层面**：用户画像、消费偏好、使用场景、满意度
- **运营层面**：营销策略、渠道布局、增长方式

### 3.3 信息采集的关键动作
- 做功能分析时，**必须把竞品每个功能都用一遍**
- 截图留存，记录操作路径和关键节点（后续绘图非常有用）
- 收集产品数据**量级**而非绝对值，作为参考依据

### 关键注意事项
1. **信息不等于洞察，数据不代表结论** —— 如果信息不能产生结论，就是无效信息
2. 信息要扣题，只采集与分析目标相关的内容
3. 五大灵魂拷问检验信息质量：
   - 你要解决什么问题？
   - 哪些信息对解决这个问题真正有用？
   - 你是在哪里找的信息？
   - 你的分析是主观还是客观，是表面还是本质？
   - 你的结论是什么，对项目有什么具体帮助？

## 四、建立分析框架（How — 维度）

### 价值定位
没有框架的竞品分析就是流水账。框架的作用是把散乱的信息组织成有逻辑的结构，确保分析不遗漏关键维度、不偏离核心目标。同时，框架也是团队协作的共识基础——所有人按同一套维度分析，结论才能横向比较。

### 工作内容
1. **选择分析维度**：根据目标从四大核心维度（定位/功能/商业/运营）中选取需要的子集，不必面面俱到
2. **确定拆解深度**：对每个维度，按"事实层→动机层→效果层"三层深入，不停留在表面动作
3. **匹配场景化框架**：如果分析对象是营销活动用"背景→目标→策略→创意→执行→效果"框架；如果是产品定位用"用户→场景→问题→解决方案→支撑点"框架
4. **统一评分标准**：如果需要量化对比，提前定义每个维度的评分规则（如 1-5 分制），确保多人分析时标准一致

### 产出物
→ **分析框架文档**：包含选定的分析维度、拆解层级、评分标准，作为数据对比与可视化的结构骨架。

### 4.1 四大核心分析维度

#### 维度一：产品定位与目标用户
- 目标用户是谁？核心场景是什么？解决了什么痛点？
- 公式：这是一个为【目标用户】，在【使用场景】下，解决【某类问题】的【产品品类】
- 用户分析三层面：
  - **用户画像**：性别、年龄、城市等级、收入水平、职业、兴趣偏好
  - **消费偏好**：品牌认知、价格敏感度、消费习惯
  - **潜在动因**：焦虑缓解、寻求安全感、自我实现、归属与认同等深层心理需求

#### 维度二：功能与体验
- 拆解为核心功能 vs 辅助功能
- 对比关键路径上的表现差异
- 包含视觉层面和交互层面

#### 维度三：商业模式
- 如何赚钱：会员订阅、广告、交易佣金、增值服务？
- 定价策略、免费版与付费版权益划分

#### 维度四：运营与增长
- 用户增长策略：裂变活动、内容运营、渠道投放
- 上市节奏、预算分配、平台组合、内容策略

### 4.2 拆解的三层深度（藏锋模型）

| 层次 | 核心问题 | 分析要点 |
|-----|---------|---------|
| **事实层** | 做什么？ | 具体动作、时间节奏、资源分配 |
| **动机层** | 为何做？ | 项目背景、目标、策略选择 |
| **效果层** | 做得如何？ | 数据表现、关键成功因素、失败原因 |

> 拆到最后，要找到决定项目成败的**根本变量**。

### 4.3 场景化分析框架

#### 营销传播分析六维度
```
背景 → 目标 → 策略 → 创意 → 执行 → 效果
```
- 背景：必要性 + 可能性
- 目标：关注的指标层次，何为主何为次
- 策略：实现目标的路径选择
- 创意：是否遵循策略，是否与用户同频
- 执行：渠道、资源、时间节奏
- 效果：曝光/互动/转化/效率四类指标

#### 产品定位五大要素
```
用户 → 场景 → 问题 → 解决方案 → 支撑点（RTB）
```
- 场景价值判断：高频刚需 > 低频高价值 > 创造新场景
- 问题三要点：痛点（不解决不行）、痒点（解决更好）、爽点（离不开）
- 解决方案三层面：功能层、情绪层、社交层
- 支撑点：技术证明、信任背书、口碑效应、设计细节、品牌势能

#### 产品上市分析要素
```
上市节奏 → 预算分配 → 平台组合 → 内容策略 → 投放动作 → 商业结果
```

#### 品牌升级分析要素
```
过去什么样 → 面临什么问题 → 要升级成什么样 → 做了哪些事
```
三大场景：年轻化、高端化、多元化

## 五、数据对比与可视化（How — 呈现）

### 价值定位
信息和分析如果不可视化，团队很难形成共识。图表的作用不是"好看"，而是让差异一目了然、让结论有据可查。一张好的对比图胜过十页文字描述。这一步是从"分析者的脑中"到"团队的共识"的关键转化。

### 工作内容
1. **按分析框架整理数据**：将第三步采集的信息档案，按第四步定义的维度和评分标准填入对比矩阵
2. **量化评分**：对每个竞品的每个维度打分，确保同一维度的评分标准一致
3. **选择合适的图表类型**：功能差异用对比矩阵，综合实力用雷达图，体验差异用用户旅程图，战略定位用 SWOT，优先级用四象限图
4. **标注关键发现**：在图表上用颜色/标注突出显著差异点，引导读者关注核心结论
5. **附上数据来源**：每个图表下方注明数据出处和采集时间，确保可追溯

### 产出物
→ **竞品对比图表集**：包含功能矩阵、雷达图、SWOT 等可视化产物，配以关键发现的文字标注，作为结论推导的直接依据。

### 5.1 核心数据收集

| 数据类型 | 具体指标 |
|---------|---------|
| **基础数据** | 日活/月活、使用时长、下载次数、版本号、最后更新时间 |
| **趋势数据** | 用户增长曲线、注册/下载趋势、排名变化、是否为公司主盈利产品线 |
| **效果指标** | 曝光（播放/阅读/话题热度）、互动（点赞/评论/转发/UGC）、转化（PV/UV/加购/成交/ROI）、效率（投产比） |

### 5.2 五种高频可视化图表

| 图表类型 | 适用场景 | 要点 |
|---------|---------|-----|
| **功能对比矩阵** | 快速比较多竞品功能差异 | 横轴=竞品，纵轴=功能点，√/× 标注 |
| **雷达图** | 多维度综合实力对比 | 评分维度：功能丰富度、易用性、性价比、稳定性、设计美观度 |
| **用户旅程地图** | 关键路径体验差异 | 分解全流程，逐步对比体验差异 |
| **SWOT 分析图** | 综合评估相对位置 | S优势/W劣势/O机会/T威胁 |
| **四象限图（波士顿矩阵）** | 功能/业务线优先级 | 明星（加大投资）、金牛（维持收割）、问题（选择性投资）、瘦狗（考虑放弃） |

## 六、得出结论与行动建议（So What）

### 价值定位
结论是竞品分析的终极产出。前面五步的所有工作——目标定义、竞品筛选、信息采集、框架分析、数据可视化——都是为这一步服务的。没有结论的竞品分析只是展示报告，无法指导决策，等于白做。这一步的价值在于：把"别人做了什么"转化为"我们该怎么做"。

### 工作内容
1. **从图表中提炼关键发现**：逐张审视对比图表，列出每个维度上我们与竞品的核心差异（优势和劣势）
2. **回答四个核心问题**：竞品做对了什么？短板在哪？我们的差异化机会是什么？接下来优先做什么？
3. **推导行动建议**：按"借鉴什么→规避什么→接下来怎么做"的逻辑，输出分层行动清单
4. **用一句话总结核心结论**：如果只能告诉 leader 一句话，那句话是什么？
5. **对齐组织协作**：团队负责"入口"（信息收集+分析+结论），leader 负责"出口"（判断+决策）

### 产出物
→ **竞品分析报告**（最终交付物）：包含分析背景、竞品概况、对比图表、核心结论、行动建议（短期/中期/长期），可直接用于决策会议。

### 6.1 结论必须回答的四个问题
1. 竞品做对了什么？哪些值得借鉴？
2. 竞品的短板在哪里？有没有弯道超车的机会？
3. 我们的差异化机会是什么？如何避免同质化竞争？
4. 接下来三个月，我们该优先做什么？

### 6.2 结论质量标准
- **必须有结论**：没有结论的竞品分析是展示报告，没有意义
- **结论要真实**：是推导出来的，不是硬加上去的（错误结论比没有结论更可怕）
- **结论要落地**：有策略性、极简、能引导执行
- **结论要分层**：借鉴什么？规避什么？接下来怎么做？

### 6.3 行动建议格式
```
一句话核心结论

短期（1个月）：...
中期（3个月）：...
长期（半年）：...
```

### 6.4 组织协作视角
- **团队负责入口**：信息收集 + 拆解分析 + 提出结论
- **Leader 负责出口**：做判断 + 做决策
- 竞品分析是为了帮助决策，而非替代决策

### 关键注意事项
1. 同样的分析内容，不同人做出来千差万别 —— 差别在于看待角度和得出的结论
2. 好的竞品分析 = 结构化框架收集信息 + 可视化图表呈现结论
3. **分析只是手段，洞察才是价值所在** —— 通过动因找本质，产生启发，指导行动

## SOP 流程总览

```
┌─────────────────┐
│ 1. 明确目标      │  为什么做？要解决什么问题？
└───────┬─────────┘
        ▼ 产出：分析目标说明书
┌─────────────────┐
│ 2. 筛选竞品      │  分析谁？（核心/标杆/间接/翘楚/避坑）
└───────┬─────────┘
        ▼ 产出：竞品清单表
┌─────────────────┐
│ 3. 信息采集      │  采集什么？从哪里采集？
└───────┬─────────┘
        ▼ 产出：竞品信息档案（每竞品一份）
┌─────────────────┐
│ 4. 分析框架      │  用什么维度分析？（定位/功能/商业/运营）
└───────┬─────────┘
        ▼ 产出：分析框架文档（维度+评分标准）
┌─────────────────┐
│ 5. 数据可视化    │  用什么图表呈现？（矩阵/雷达/旅程/SWOT/四象限）
└───────┬─────────┘
        ▼ 产出：竞品对比图表集
┌─────────────────┐
│ 6. 结论落地      │  借鉴什么？规避什么？怎么做？
└─────────────────┘
        ▼ 产出：竞品分析报告（最终交付物）
```
